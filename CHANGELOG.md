# Изменения

## 1.1.0 — 2026-09-06

Сеть и секреты. Репозиторий теперь можно склонировать, получать и отправлять
изменения, не выходя из приложения и по-прежнему не используя системный git.

### Сеть

- Транспорт git на чистом Go: pkt-line, side-band, согласование возможностей,
  протоколы версий 1 и 2.
- Smart HTTP и HTTPS с повтором запроса при 401, `git://`, SSH и локальные пути.
- Локальный транспорт читает репозиторий на диске напрямую: клон с соседней
  папки работает без сети и без внешних программ.
- Настоящее согласование объектов по раундам `have`, а не один шаг.
- Запись pack-файлов с дельта-сжатием и потоковый приём с достройкой thin-пака.
- `clone` (полный, bare, по ветке, одна ветка, поверхностный), `fetch`, `pull`
  только перемоткой, `push`, `prune`, управление удалёнными репозиториями.
- `FETCH_HEAD` и файл `shallow` пишутся в формате git.
- `--force-with-lease`: отправка отклоняется, если удалённая ветка ушла вперёд.

### Секреты

- Хранилище `vault.bin`: XChaCha20-Poly1305, ключ содержимого под слотами
  DPAPI (Windows), Secret Service (Linux), мастер-пароль (Argon2id) и файл ключа.
- Учётные данные ищутся по самому длинному совпавшему префиксу адреса.
- SSH: ключи из каталога и из хранилища, ssh-agent через сокет и именованный
  канал Windows, `known_hosts` с подтверждением неизвестного ключа и отказом
  при изменившемся.
- Секреты живут в `[]byte`, зануляются после использования и не попадают в лог.

### Интерфейс

- Диалог клонирования с проверкой адреса и выбором ветки.
- Меню «Удалённые» и кнопки Pull, Sync, Push работают по-настоящему: ход
  операции виден в окне с логом, операцию можно отменить.
- Диалоги учётных данных, подтверждения ключа хоста и разблокировки хранилища.
- Страницы настроек «Учётные данные» и «SSH-ключи»: список, добавление,
  удаление, мастер-пароль.
- Авто-fetch по таймеру и расхождение с upstream в панели репозиториев
  и строке состояния.
- Настройки: стратегия pull, удалённый репозиторий по умолчанию, очистка
  исчезнувших веток при получении, глубина клона.

### Чего нет

Merge, rebase, cherry-pick, revert, reset, worktree, разрешение конфликтов,
построчный stage.

## 1.0.0 — 2026-09-05

Первый релиз. Настольный git-клиент для Windows и Linux с собственной
реализацией git на чистом Go: системный git не нужен, CGO не используется.

### Ядро git

- Объекты, свободные и упакованные, дельты, `.idx`, alternates.
- Ссылки: свободные и `packed-refs`, символические, reflog, транзакции с `*.lock`.
- Конфигурация git с `include` и `includeIf`.
- Индекс версий 2, 3 и 4 с cache tree.
- `.gitignore` и `.gitattributes` с общим движком wildmatch.
- Разбор ревизий по правилам gitrevisions и обход графа коммитов.
- Diff: Майерс и гистограмма, определение переименований, unified и stat.
- Статус рабочей копии в семантике `git status --porcelain=v2`, включая
  игнорируемые пути и файлы без изменений.
- Обрыв истории на коммитах из файла `shallow` — журнал работает на клонах `--depth`.
- Операции записи: stage, unstage, discard, commit, создание, переименование
  и удаление веток, переключение ветки.

### Интерфейс

- Док-панели с сохраняемой раскладкой, темы Windows 11, русский и английский язык.
- Дерево репозиториев с группами, рабочими копиями и каталогами рабочей копии.
- Дерево веток с локальными, внешними, тегами и stash.
- Панель файлов с фильтрами по имени, состоянию и каталогу.
- Журнал коммитов с подгрузкой по мере прокрутки.
- Двухпанельный diff.
- Окно длительной операции: бесконечный прогресс, лог действий, отмена.
- Слежение за репозиторием: изменения, сделанные другим git, подхватываются сами.

### Чего нет

Сеть (clone, fetch, pull, push), хранилище секретов, SSH, merge, rebase,
cherry-pick, stash-операции, построчный stage.
